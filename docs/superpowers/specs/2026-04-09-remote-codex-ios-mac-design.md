# iPhone 远程连接 Mac 上 Codex CLI 方案设计

## 目标

产出一份可本地直接打开、以桌面端阅读为主的 HTML 说明页，完整解释如何通过 iPhone 远程连接到 Mac，并继续使用本机的 `Codex CLI` 执行编程任务。

核心方案固定为：

`iPhone + Tailscale + Termius -> Mac Remote Login(SSH) -> tmux -> Codex CLI`

## 设计结论

这是一个“远程终端型”方案，不是“消息派单型”方案。手机不是给中间服务发指令，而是通过私网直接接入 Mac 的 shell，会话保持由 `tmux` 负责，AI 编程代理仍然是 Mac 本机上的 `Codex CLI`。

## 设计原则

1. 让链路尽量短，避免增加不必要的代理层。
2. 让连接尽量稳定，弱网或 iOS 后台切换时不丢失工作会话。
3. 让安全边界尽量清晰，不暴露公网 SSH 端口。
4. 让使用动作尽量接近“一键进入 Codex 会话”。

## 页面范围

HTML 页面需要覆盖以下内容：

- 一句话总览方案
- 全链路架构图
- 每个组件的职责与原理
- iPhone 端需要做的事情
- Mac 端需要做的事情
- 连接时中间消息如何流转
- 日常使用方式
- 安全建议与故障排查

## 信息结构

页面采用导航式单页结构，以桌面端三栏工作台为主：左侧导航、中间正文、右侧快速信息栏；移动端仅退化为可阅读版本，不作为主设计目标。

主要章节如下：

1. 总览
2. 架构
3. 原理
4. 全链路消息流
5. Mac 端配置
6. iPhone 端配置
7. 日常使用
8. 安全边界
9. FAQ

## 视觉方向

- 视觉基调：像“桌面操作蓝图”，不是普通博客页
- 色彩：深墨绿/深灰底，配暖白文本和青绿色强调色
- 布局：首屏突出一条明确链路，正文按 PC 浏览器的阅读密度和回查效率来组织
- 动效：仅保留轻量进入动画、导航高亮、链路节点呼吸效果

## 技术实现

- 单文件 HTML
- 内联 CSS 与少量原生 JavaScript
- 不依赖外部框架或构建步骤
- 优先保证本地 `file://` 打开也能正常浏览
