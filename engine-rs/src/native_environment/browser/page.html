Chrome environment check

This page observes this Chrome context only. It sends time zone, language, client hints and screen measurements to the temporary local Agent Manager service. No external server is contacted.

Chrome may record this page in its normal history or cache. No browser preferences, system settings, accounts or shell files are changed.

Reading browser values… The local service closes after this result, cancellation, or 45 seconds.

    

    GeoIP, WebRTC, Canvas/WebGL, fonts, clock drift and TLS fingerprints are not checked. Screen and client hints are observations; these values do not identify the browser binary or prove all websites see the same environment.
